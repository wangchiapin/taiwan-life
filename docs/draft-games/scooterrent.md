## 劇情

Ami 的朋友要來玩，Ami 用 LINE 請玩家去機車行租一台「一百二十五西西」的機車，每局隨機租一、二或三天。玩家身上有機車駕照，和五百、一千、兩千元鈔票各一張。流程：走進機車行 → 出示駕照 → 說車種和天數 → 店員複誦（可能聽錯）→ 看契約與保險、簽名 → 報租金（可能多報）→ 付錢、核對找的錢（可能找錯）→ 借安全帽 → 取車檢查（刮痕畫在車況單上、拍照）→ 過幾天還車，店員檢查（可能誤說有新刮傷要扣錢）→ 傳訊息給 Ami。
（總清單重點「出示駕照、確認保險、借安全帽、還車時檢查有沒有刮傷」。）

## 關卡流程（ORDER）

START → ARRIVE → LICENSE → ORDER（說車種和天數）→ **CONFIRM（複誦，45% 聽錯）** → INSURE（看契約、保險、簽名）→ **PAY（報價，45% 多報）** → PAY_FIX（多報被抓到後重新付）→ **CHANGE（找錢，40% 找錯）** → HELMET → CHECKBIKE → **RETURN（還車檢查，40% 店員誤說有新刮傷）** → END → RESULT。

## 對方出錯點與機率

| 關卡 | 錯誤機率 | 怎麼出錯 | 正解 |
|---|---|---|---|
| CONFIRM | 45% | 店員把車種（125↔150 西西）或天數聽成別的（二選一，各一半） | 沒錯→「對，沒錯，謝謝。」；錯→「不好意思，我要的是○西西，租○天。」 |
| PAY | 45% | 店員報的錢比租車單多（多五十元「安全帽費」或一百元「一天保險費」） | 沒錯→「給你○元。」；錯→「不好意思，好像算錯了，應該是○元吧？」 |
| CHANGE | 40% | 找的錢多或少十或二十元 | 沒錯→「好，謝謝。」；錯→「不好意思，好像找錯了，應該找○元吧？」 |
| RETURN | 40% | 店員說車子左邊有新刮傷要扣兩百元，其實取車時就有（單子上有、也拍照了） | 沒錯→「好，謝謝。」；錯→「不好意思，這道刮痕取車的時候就有了，單子上有寫，我也有拍照。」 |

四關都用共用的 `catchState`／`payStates`：①沒錯／謝謝　②有禮貌指出問題（對方沒錯時，指出的內容是錯的）　③沒禮貌（永遠錯）。抓到錯之後店員道歉並補（更正車種天數、報對價錢、補找錢、不扣錢）。
**固定正解的關卡**（選錯留在原關、扣十分）：ARRIVE（要說清楚想租車）、LICENSE（出示自己的駕照）、INSURE（看契約、出事要報警並通知店家）、HELMET（挑合適沒裂痕的帽子、扣好帶子）、CHECKBIKE（刮痕畫在單子上並拍照）。
**ORDER 關是「先記下來」的關卡**：玩家說錯車種或天數，會扣十分，但不擋住，遊戲照他「實際說的」往下走（複誦、租車單、價錢都用實際說的算）。

## 價錢與計算邏輯

- 租金 `t.total` ＝實際說的天數 × 每天租金（125 西西 300 元、150 西西 400 元，待確認）；Ami 要的車種與天數另外記（`t.cc`、`t.days`）。
- 報價 `t.said`＝總價或總價加五十／一百元（共用 `initPay`）；鈔票由 `billFor` 決定（≤500 付五百、≤1000 付一千、其餘兩千）；找零 `t.change`＝鈔票−總價，實際找的 `t.given` 可能差十或二十元。
- 沒有押金（見待確認）。

## 正解怎麼判定

好結局＝錯誤 ≤ 2 次，**而且最後實際租到的車種與天數和 Ami 要的完全一樣**（`t.oCc===t.cc && t.oDays===t.days`）。ORDER 關說錯，即使其他都對也是壞結局，Ami 會說「我要的是……怎麼租成……」。

## 查證來源

- 取車後要立即檢查車況、可拍照存證；契約要載明租金、費率與租賃期間；停車費與違規罰鍰由消費者負擔；還車要拍照留存；擦撞要立即報案並通知業者；機車故障可要求減免租金、換車或終止契約：[台中市和平區公所「消費者保護宣導 機車租賃新規範」](https://www.heping.taichung.gov.tw/media/779618/消費者保護宣導-機車租賃新規範-出遊代步停聽看.pdf)。
