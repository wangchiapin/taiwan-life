## 劇情

玩家的髒衣服堆很多，Ami 用 LINE 叫他去自助洗衣店：每局隨機用小型（約八公斤，洗衣四十元＋自動洗劑十元＝五十元）或中型（約十二公斤，洗衣六十元＋十元＝七十元）洗衣機，洗劑用機器自動加，洗好後烘乾二十或三十分鐘（烘衣機一分鐘一元，只收十元硬幣）；身上只有一張一百元鈔票，要先換十個十元硬幣。衣服是 T 恤、牛仔褲、襪子，「沒有外套」。
流程：進店選空的機器 → 跟店員換零錢（數硬幣）→ 檢查口袋放衣服 → 店員說洗衣的錢（對螢幕）→ 投幣 → 洗好把濕衣服拿去烘 → 店員幫忙設定烘衣時間 → 烘衣投幣 → 拿衣服核對有沒有別人的東西 → 傳訊息給 Ami。
（總清單重點「投幣、選洗衣與烘衣程序」：投幣＝COINS／INSERT／DRYPAY，洗衣程序＝LOAD／WASHSET，烘衣程序＝WAIT／DRYSET／TAKEOUT。）

## 關卡流程（ORDER）

START → ENTER（選空的機器）→ **COINS（換零錢，40% 少給一個）** → LOAD（檢查口袋、關好門）→ **WASHSET（店員說洗衣的錢，45% 說錯，螢幕才對）** → INSERT（投幾個十元）→ WAIT（洗好後拿去烘衣機）→ **DRYSET（店員設定烘衣時間，45% 設成另一個時間）** → DRYPAY（烘衣投幾個十元）→ **TAKEOUT（拿衣服，40% 烘衣機裡混進別人的紅色外套）** → END → RESULT。

## 對方出錯點與機率

| 關卡 | 錯誤機率 | 怎麼出錯 | 正解 |
|---|---|---|---|
| COINS | 40% | 店員說「十個十元」，實際（畫面上）只有九個 | 沒錯→「好，謝謝。」；錯→「不好意思，這裡好像只有九個，應該是十個吧？」 |
| WASHSET | 45% | 店員說的錢和洗衣機螢幕上的不同（差十到二十元） | 沒錯→「好，我知道了。」；錯→「不好意思，螢幕上寫的是○元。」 |
| DRYSET | 45% | 店員設成另一個分鐘數（二十↔三十），和 Ami 要的不同 | 沒錯→「好，麻煩你了。」；錯→「不好意思，我要烘○分鐘，○元。」 |
| TAKEOUT | 40% | 拿出來的衣服裡有一件不是你的紅色外套 | 沒錯→「都拿完了，謝謝。」；錯→「不好意思，這件紅色外套不是我的。」 |

四關都用共用的 `catchState`：①沒錯／謝謝　②有禮貌指出問題（對方沒錯時，內容是錯的）　③沒禮貌（永遠錯）。抓到錯之後店員道歉並補（多給一個硬幣、改回正確金額／時間、把外套收走）。玩家不能「收下錯誤」往前走，所以好壞結局（錯誤 ≤ 2 次好結局）一定和最後實際拿到的東西一致。
其他關卡是固定正解，錯誤答案：ENTER（動別人「使用中」的衣服、把衣服放地上等）；LOAD（口袋不檢查、塞太滿）；INSERT（少投一個、把鈔票塞進投幣孔）；WAIT（濕衣服裝袋子回家、留在洗衣機裡明天拿）；DRYPAY（多投一個、先烘後付）。

## 價錢與計算邏輯

- 洗衣價錢 `washP`＝尺寸價（小型四十、中型六十）＋自動加洗劑十元＝五十或七十元；螢幕上顯示的永遠是對的，店員說的 `washSaid` 另外記。投幣個數＝`washP/10`。
- 烘衣：一分鐘一元，`dry`＝二十或三十，投幣個數＝`dry/10`。
- 換零錢：一百元＝十個十元；洗衣用掉 5 或 7 個，剩下 5 或 3 個，一定夠烘衣（最多用 3 個）。畫面上的 🪙 數量是店員真正給的 `coinGot`（九或十）。
