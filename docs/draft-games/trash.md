## 劇情

主角新搬進一棟公寓，Ami 用 LINE 說：晚上有垃圾車，要自己拿著垃圾下樓；一般垃圾要裝專用垃圾袋，資源回收要先分類，吃剩的菜是廚餘，要等車來再倒進廚餘桶。主角家有一袋垃圾、一個寶特瓶、一個紙箱、一個沾了很多油的披薩盒。流程：看一樓公告（垃圾車時間、地點、今天收哪一類資源回收）→ 問鄰居阿姨（可能說錯時間或地點）→ 回家整理要倒的東西 → 下樓等垃圾車 → 清潔隊員說今天收哪一類資源回收（可能說錯）→ 丟東西、倒廚餘 → 問阿姨沾了油的披薩盒怎麼丟 → 傳訊息給 Ami。
（總清單重點「記得時間與地點、垃圾與資源回收怎麼分、問鄰居」。）

## 關卡流程（ORDER）

START → BOARD（看公告）→ **ASK（問鄰居，45% 說錯時間或地點）** → HOME（整理：實際帶什麼先記下來）→ ARRIVE（等車，垃圾不落地）→ **TRUCK（隊員說今天收哪一類，45% 說錯）** → THROW（廚餘倒廚餘桶）→ ASKOIL（問阿姨披薩盒）→ OIL（照阿姨的話丟）→ END → RESULT。

每局隨機：今天星期幾（一、二、四、五、六）→ 決定今天收「平面類（紙類，一、五）」還是「立體類（瓶罐，二、四、六）」；垃圾車時間（晚上六點半／七點／七點半／八點）；地點（巷口的便利商店前面／社區旁邊的小公園）。

## 對方出錯點與機率

| 關卡 | 錯誤機率 | 怎麼出錯 | 正解 |
|---|---|---|---|
| ASK | 45% | 阿姨記錯垃圾車的時間（改成另一個時間）或地點（說成另一個地點），二選一各一半；畫面上的公告是對的 | 沒錯→「好，謝謝阿姨。」；錯→「不好意思，我看公告上寫的是○○，在○○。」 |
| TRUCK | 45% | 隊員把今天收的資源回收類別說成另一類（平面↔立體）；公告是對的 | 沒錯→「好，謝謝。」；錯→「不好意思，公告上寫今天收○○類。」 |

兩關都用共用的 `catchState`：①沒錯／謝謝　②有禮貌指出問題（對方沒錯時，指出的內容是錯的）　③沒禮貌（永遠錯）。抓到錯之後對方道歉並更正。
**固定正解的關卡**（選錯留在原關、扣十分）：BOARD、ARRIVE（拿在手上等車，不放地上、不丟別人家桶子）、THROW（剩菜倒進廚餘桶、髒袋子丟垃圾車）、ASKOIL（有禮貌地問）、OIL（沾到油的紙盒丟一般垃圾）。
**HOME 關是「先記下來」的關卡**：玩家選的是「垃圾裝專用垃圾袋／黑色塑膠袋」和「帶今天收的／不收的那一類資源回收」，選錯扣十分但不擋住，往下走；到 THROW 時隊員依「實際帶的」反應（不是專用袋：不收；帶了今天不收的那類：退收，帶回去）。

## 價錢或計算邏輯

這個遊戲沒有付錢找零（專用垃圾袋的價格、隨袋徵收的費用沒有做，見待確認）。「計算」是核對：公告上的時間、地點、今天收哪一類，對照鄰居與隊員說的。

## 正解怎麼判定

好結局＝錯誤 ≤ 2 次，**而且最後實際倒掉的東西都被收了**：一般垃圾裝在專用垃圾袋（`t.bagOK`）、帶的資源回收是今天收的那一類（`t.recOK`）。HOME 選錯即使其他都對也是壞結局，Ami 會說「你的垃圾沒有被收」或「被退收了」。
