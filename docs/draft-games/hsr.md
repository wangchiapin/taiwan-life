## 劇情

Ami 先到台中了，在高鐵站出口等你。她用 LINE 說：搭高鐵幾點幾分那班，每一局隨機是下面三種之一：
- **標準車廂對號座**（55%）：Ami 說「買標準車廂的對號座就好，商務車廂太貴了」。
- **商務車廂**（25%）：Ami 說「今天坐商務車廂，錢我晚點轉給你」。
- **自由座**（20%）：Ami 說「買自由座就好，比較省錢，不用指定座位」。

主角在高鐵台北站服務櫃檯買票 → 站務員可能說錯 → 付錢找錢 → 檢查車票有沒有印錯 → 票閘 → 看指示牌選南下 → 看看板用車次找自己的車（有的車不停台中）→ 到候車位置 → 找位子（對號座有時有人坐；自由座有時座位上放著包包）。

## 關卡流程（ORDER）

START → COUNTER（說去哪裡、哪一種座位、幾點）→ **SOLD（只有標準車廂、40%：這班標準車廂對號座滿了，只剩商務車廂和自由座；要問下一班，開車時間 +20 分）** → **TK_CHECK（站務員複誦：目的地／座位種類／開車時間，45% 說錯一項）** → **PAY（報價，45% 多算一張）→ PAY_FIX → CHANGE（找錢，40% 找錯）** → **TICKET（車票印出來，40% 印錯目的地或時間）** → GATE（車票插進票閘）→ DIRECTION（看指示牌：南下／北上）→ **BOARD（看板上三班車，用車次選；其中一班同時間但不停台中，一班比較早）** → CAR（找候車位置：對號座／商務看車票上的車廂；自由座看看板上的自由座車廂）→ **SEAT（45%：對號座有人坐你的位子／自由座座位上放著包包）** → END → RESULT。

## 對方出錯點與機率

| 關卡 | 錯誤機率 | 怎麼出錯 | 正解 |
|---|---|---|---|
| SOLD | 標準車廂的 40% 出現 | 原本那班標準車廂對號座滿了 | 問下一班還有沒有標準車廂對號座（買商務、買自由座都是錯） |
| TK_CHECK | 45% | 目的地／座位種類（標準↔商務、自由座→標準）／開車時間（+20 分）其中一項說錯 | 沒錯→「對，沒錯。」；錯→有禮貌說出正確那一項 |
| PAY | 45% | 多算一張票（例：700 → 1400） | 沒錯→給鈔票；錯→指出應該是幾元 |
| CHANGE | 40% | 找的錢差 ±10 或 ±20 | 沒錯→謝謝；錯→指出應找的金額 |
| TICKET | 40% | 目的地或時間印錯 | 沒錯→謝謝；錯→指出正確的並請他重印 |
| SEAT | 45% | 有乘客坐在你的位子上／自由座位子上有包包 | 有人→有禮貌地說（對號座：「這是我的位子，我的票是…」；自由座：「請問這個位子有人坐嗎？可以請您把包包拿開嗎？」）；沒人→坐下 |

三個選項固定寫法：①沒錯／謝謝 ②有禮貌指出問題（對方沒錯時，內容是錯的數字／內容）③沒禮貌（永遠錯）。共用的 `catchState`／`payStates` 讓玩家不能「收下錯誤」往前走，所以好壞結局（錯誤 ≤ 2 次好結局）一定和最後實際拿到的東西一致。

## 價錢與計算邏輯

- 票價（台北→台中，全票）：標準車廂對號座 700 元、商務車廂 1,250 元、自由座 675 元。**來源是交通喵整理的票價表（查證日期標 2026-10-10，但頁面另一處標 2026-08-12 同步，兩個日期不一致），是不是現行價待確認。**
- 多算時 `said` = 實際票價 ×2（1400／2500／1350），你給的鈔票用 `billFor()`：≤1000 → 一千元、其餘兩千元（我的狀況寫「一千元和兩千元的鈔票」）；找錢＝你給的 − 真正票價。
- 時間：Ami 說的時間 `t1`（07:05–19:45，整點後 05／25／45 分）；賣完時實際搭 `t1+20`。念法 `tmZh()`：「八點二十五分」「十五點零五分」（用二十四小時制念；待確認：口語會不會改念「下午三點零五分」）。
- 車次（0615、0617…）、車廂、座位（3–18 排，A–E 座；商務車廂 A／C／D）都是隨機的，念數字用 `zhNum`／`zhDigits`。商務車廂固定 6 車、自由座固定 1–3 車（待確認）。

## 正解怎麼判定

一般關卡：選錯扣十分並留在原關。選項用 `rotOf` 隨機排。GATE 的錯誤答案是「拿悠遊卡刷票閘」「從旁邊走進去」；DIRECTION 的錯誤答案是「走北上」「跟著別人走」；BOARD 看板有三班車（你的、同時間但不停台中的、比較早的），用車次判斷；CAR 的錯誤答案是相鄰車廂（對號座／商務），或商務車廂和對號座車廂（自由座）。

## 待確認

1. 票價 700／1250／675 是不是 2026 年 11 月現行價（來源兩個日期不一致）。
2. 商務車廂是不是固定 6 車、自由座是不是 1–3 車：來源只說自由座每班 2–8 節不等，遊戲先簡化成固定 1–3 車（看板上會寫出來）。商務車廂座位字母（A／C／D）也是簡化。
3. 自由座車票是不是「指定當日當班次」：遊戲目前當作要指定車次（和標準車廂一樣說時間）；來源只說自由座要在搭乘當日於車站購買。
4. 一般悠遊卡能不能直接進高鐵站：遊戲把「拿悠遊卡刷票閘」當錯誤選項（因為已經買了紙本車票）；來源說的是「悠遊聯名卡」＋自動儲值可以感應進站，遊戲的錯誤說明寫「一般悠遊卡不能直接進高鐵站」要再確認。
5. 紙本車票是「插進票閘」還是「掃 QR／刷條碼」、台北站月台是否一定先經過手扶梯，都是常見做法，沒有查證。
6. 時間用二十四小時制念（「十五點零五分」），口語是否會不一樣；SOLD 的「下一班 +20 分」是示意，不是真實班次。
